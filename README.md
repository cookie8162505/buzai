# 部材検査 試作版

iPhoneのSafariで動く部材検査の試作です。サーバーは不要で、GitHub Pagesに置くだけで動きます。

## 置き方
1. このフォルダの中身（`index.html` `marker.html` `lib/`）を、そのままリポジトリに上げる
2. Settings → Pages で公開する
3. iPhoneで `https://<ユーザー名>.github.io/<リポジトリ名>/` を開く
   （カメラは https でないと動かないので、必ずGitHub PagesのURLから開く）

## 流れ
1. バーコード（TOPオーダー）… カメラで読むか、手で入れる。テスト用 01〜03
2. 部材と図面 … テスト用データとダミー図面を表示 →「図面を確定」
3. 撮影 … 背面カメラ
4. 測る … 写真の中のマーカーを自動で探し、2点をタップすると長さ（mm）が出る
5. OK・NG … 寸法の項目は公差から自動判定（手で変更も可）
6. 検査票 … 紙と同じ並びで表示し、Excelで保存。写真は共有から保存

左下に「次にやること」を表示します。

## マーカー
`marker.html` を **実際のサイズ（100%）** で印刷し、黒い四角の一辺を定規で測って、アプリに入れてください。
辞書は ArUco MIP_36h12、ID 0〜3。

## 試作の範囲（できていないこと）
- 部材データ・図面はテスト用（`index.html` の `TEST_DATA`）
- シャッター長押しのパノラマ測定は未実装（1枚の写真で測る）
- Excelに写真は入らない（ファイル名だけ記録）
- 共有フォルダや梱包指示EXEとはつながっていない（履歴はその端末のブラウザ内だけ）

## 使っている部品（lib/）
- js-aruco2（マーカー検出、BSDライセンス）
- @zxing/library 0.21.3（バーコード読み取り）
- SheetJS xlsx 0.18.5 mini（Excel保存）
